# ✅ **5. בדיקת config-reader (ערך תקין)**
```bash
tmp=$(mktemp)
printf 'KEY=plain\n' > "$tmp"
source scripts/lib/config-reader.sh
value=$(get_conf KEY "$tmp")
rc=$?
rm -f "$tmp"
echo "config_reader_valid_rc=$rc value=$value"
```

פלט תקין:
```
config_reader_valid_rc=0 value=plain
```

# ✅ **6. בדיקת config-reader (חסימת ; זדוני)**
```bash
tmp=$(mktemp)
printf 'KEY=value; rm -rf /\n' > "$tmp"
source scripts/lib/config-reader.sh
if get_conf KEY "$tmp"; then
  echo "config_reader_dangerous=FAIL"
else
  echo "config_reader_dangerous=OK"
fi
rm -f "$tmp"
```

פלט תקין:
```
config_reader_dangerous=OK
```


בדיקת טעינה:
```bash
python3 - <<'PY'
import importlib.util
spec = importlib.util.spec_from_file_location('badusb', 'scripts/badusb-monitor.py')
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)
print("API_BLOCK_URL =", mod.API_BLOCK_URL)
assert "localhost" in mod.API_BLOCK_URL or "127.0.0.1" in mod.API_BLOCK_URL
PY
```
